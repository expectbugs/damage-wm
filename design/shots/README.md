# Rendered shell surfaces

Everything here except the four files listed below is generated by
`design/render_shots.py` at **true 1× 640×480**, quantised to 4bpp and priced through the
firmware's own RLE. Regenerate after any design change; `tools/lint.py` checks the results
against the ink budgets in `DESIGN.md` §4.2 and against that file's own stated measurements.

Never render at 2×. A 2× view flatters delicate type and misled the typeface evaluation for
several passes — at true scale, stroke weight decides legibility and letterform character is
secondary.

## Not ours

`launcher.png`, `music-player.png`, `settings-assistant.png`, `settings-display.png` are
